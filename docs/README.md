## Architecture

The system is divided into several modules, each with a specific responsibility:

- **Drug Data Management**: Handles drug data storage and retrieval.
- **Dosage Calculation**: Performs dosage calculations based on patient parameters.
- **Interaction Validation**: Ensures that drug interactions are safe.
- **User Interface**: Provides a user-friendly interface for input and output.
