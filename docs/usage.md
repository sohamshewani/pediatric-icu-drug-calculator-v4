# Usage

## Running the Application

To run the application, follow these steps:

1. Clone the repository.
2. Install the required dependencies.
3. Run the application.

### Prerequisites

- Python 3.8 or higher
- Poetry for project management

### Installation

1. Clone the repository
   ```sh
   git clone https://github.com/yourusername/pediatric-icu-drug-calculator.git
   ```
2. Install dependencies
   ```sh
   poetry install
   ```

### Running the Application

Run the application
   ```sh
   poetry run pediatric-icu-drug-calculator
   ```

## User Interface

- **Drug Data Entry**: Enter the drug name, dosage, route, frequency, and age range.
- **Patient Data Entry**: Enter the patient's age.
- **Result Display**: The system will display the calculated dosage or any error messages.
