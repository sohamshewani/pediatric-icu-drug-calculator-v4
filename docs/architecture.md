# Architecture

The Pediatric ICU Drug Calculator is structured into the following modules:

1. **Drug Data Management**: Manages the storage and retrieval of drug data.
2. **Dosage Calculation**: Calculates the appropriate dosage for a given drug based on patient parameters.
3. **Interaction Validation**: Validates drug interactions to ensure safety.
4. **User Interface**: Provides a user-friendly interface for interacting with the system.

Each module is designed to be modular, making the system easy to maintain and extend.
