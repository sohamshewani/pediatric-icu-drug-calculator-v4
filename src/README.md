# Pediatric ICU Drug Calculator

## Overview

This is the source code for the pediatric ICU drug calculator. The system is designed to assist in the safe and accurate calculation of drug dosages for children in a pediatric ICU setting. It is structured into several modules to manage drug data, perform dosage calculations, validate interactions, and provide a user interface.

## Files

- **drug_data.py**: Manages drug data.
- **dosage_calculator.py**: Performs dosage calculations.
- **safety_validator.py**: Validates drug interactions.
- **user_interface.py**: Provides a user interface.
- **__init__.py**: Initializes the module.
